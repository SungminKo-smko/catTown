# 나만의 작은 마을

귀여운 아이와 친구들이 함께하는 마을 시뮬레이터.

방향키, WASD 또는 화면의 방향 버튼으로 움직입니다. 직원 고용과 건물 건설, 목표, 펫 선택, 길고양이 밥 주기, 다섯 번 클릭으로 방문객 돌려보내기, 밤에 집에서 잠자기를 지원합니다.

HTML, CSS, JavaScript로 만든 정적 사이트로 빌드나 서버가 필요 없습니다.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save.

모든 게임 파일과 PNG 파일이 index.html과 같은 폴더에 있어야 합니다.

진행 상황은 각 방문자의 브라우저에 저장됩니다. 사이트 주소가 달라지면 이전 주소의 저장 상태는 자동으로 옮겨지지 않습니다.
